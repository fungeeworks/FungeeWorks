FUNGEEWORKS WEBSITE STARTER

Files:
- index.html: Responsive static website (HTML/CSS/JavaScript)
- assets/fungeeworks-logo.png: Logo asset supplied from the available Fungeeworks logo file

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome/Edge. Internet access is required for the remote Unsplash images.

HOW TO PUBLISH
Option A - cPanel/shared hosting:
1. Open your hosting control panel and File Manager.
2. Open public_html (or the domain's document root).
3. Upload index.html and the assets folder, preserving the folder structure.
4. Visit your domain and test the page on desktop and mobile.

Option B - WordPress:
This is a standalone HTML site, not a WordPress theme/plugin. You can publish it as a static site in the domain root, or use the content/design as a reference to rebuild the pages in WordPress. Do not upload index.html into WordPress Media Library expecting it to become the website.
